# Pocket Snake

A retro handheld-LCD style Snake game in a single HTML file — no build step, no dependencies.

**Play it:** https://saadscript.github.io/pocket-snake/

## Controls

- **Arrow keys / WASD** — steer
- **Space** — pause / resume
- **D-pad buttons** — on-screen controls
- **Swipe** — on phones

Walls wrap around; the snake speeds up as you eat. Your high score is saved in your browser.

## Run locally

Just open `index.html` in any browser.
